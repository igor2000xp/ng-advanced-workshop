# Project Overview

This project is an Angular workshop that covers advanced Angular concepts. It is a hands-on workshop where users can learn by doing the exercises. The workshop is divided into 7 exercises, each covering a different concept. The exercises are designed to be completed in order, as they build on each other.

The project is built with Angular 15 and uses the Angular CLI. It also uses `json-server` to create a fake REST API for the exercises.

# Building and Running

## Prerequisites

- Node.js and npm
- Angular CLI

## Installation

1.  Clone the repository.
2.  Run `npm install` to install the dependencies.

## Running the application

1.  Run `npm run server` to start the `json-server`.
2.  Run `npm start` to start the development server.
3.  Navigate to `http://localhost:4200/` in your browser.

## Running tests

Run `npm test` to run the unit tests.

# Development Conventions

## Code style

The project uses Prettier to format the code. You can run `npm run format` to format the code.

## Gitflow

The project uses the Gitflow workflow. All new features should be developed in a feature branch. When the feature is complete, a pull request should be created to merge the feature branch into the develop branch.

## Commits

The project uses the Conventional Commits specification for commit messages. This makes it easier to automate the release process and to generate changelogs.
