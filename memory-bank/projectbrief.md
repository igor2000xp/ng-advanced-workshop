# NgAdvancedWorkshop Project Brief

## Project Overview

This is an advanced Angular workshop project designed to teach and demonstrate complex Angular concepts through practical exercises. The project consists of 7 exercises, each focusing on specific Angular and RxJS concepts.

## Core Requirements

1. Functional development server environment
2. Interactive exercises that demonstrate advanced Angular concepts
3. Clear progression through increasingly complex topics
4. Practical implementation examples for each concept

## Project Goals

- Provide hands-on experience with advanced Angular concepts
- Demonstrate best practices in Angular development
- Enable learning through practical exercises
- Cover a comprehensive range of RxJS operators and patterns

## Exercise Structure

The project is organized into 7 exercises, each building upon previous knowledge:

1. **Exercise 1**: Async Operations & Template Syntax
2. **Exercise 2**: Reactive Programming & Observable Management
3. **Exercise 3**: Forms & Custom Pipes
4. **Exercise 4**: Advanced RxJS Operations
5. **Exercise 5**: Component Architecture & Communication
6. **Exercise 6**: Custom Directives
7. **Exercise 7**: Content Projection

## Technical Stack

- Angular (latest version)
- RxJS
- TypeScript
- Angular CLI

## Development Environment

- Local development server (ng serve)
- Port: 4200
- Hot reload enabled for development efficiency
