# Product Context

## Purpose

The NgAdvancedWorkshop serves as an educational platform for developers to master advanced Angular concepts through hands-on exercises. It addresses the need for practical, real-world experience with complex Angular patterns and RxJS usage.

## Problem Space

- Gap between basic Angular knowledge and advanced implementation skills
- Need for hands-on experience with RxJS operators
- Understanding complex component interactions
- Mastering template syntax and directives
- Learning best practices for reactive programming

## User Experience Goals

1. **Progressive Learning**
   - Clear exercise progression
   - Each concept builds on previous knowledge
   - Practical examples demonstrate real-world usage

2. **Interactive Development**
   - Live development server
   - Immediate feedback on changes
   - Visual demonstration of concepts

3. **Comprehensive Coverage**
   - Multiple Angular concepts per exercise
   - Integration of various RxJS operators
   - Component communication patterns
   - Advanced directive usage

## Exercise Flow

1. Start with async pipe and template basics
2. Progress to reactive programming
3. Introduce form controls and custom pipes
4. Advance to complex RxJS operations
5. Cover component architecture
6. Explore custom directives
7. Conclude with content projection

## Success Criteria

- Completion of all exercises
- Understanding of each concept demonstrated
- Ability to implement solutions independently
- Practical application of learned concepts
